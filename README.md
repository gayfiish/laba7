## Тема

Работа с базами данных в Python.

## Цель работы

Изучить основы работы с СУБД SQLite в Python: создание таблиц, вставку данных, параметризованные SQL-запросы, объединение таблиц, индексацию и тестирование базы данных.

## Выполненные задания

### Средняя сложность

**№6. Использовать параметры запроса**

Реализованы параметризованные SQL-запросы для поиска сотрудников по имени и минимальной зарплате.

Значения передаются через параметры `?`, что обеспечивает безопасную обработку пользовательских данных.

**№8. Выполнить JOIN**

Реализован INNER JOIN таблиц `employees` и `departments`.

Запрос выводит сотрудников вместе с названиями их отделов и зарплатами.

**№2. Вставить данные в таблицу**

Реализована вставка отделов и сотрудников в базу SQLite.

Предусмотрена защита от повторного добавления демонстрационных записей.

### Повышенная сложность

**№4. Индексация и поиск**

Создан индекс `idx_employees_name` для поиска сотрудников по имени.

Реализован поиск с использованием параметризованного SQL-запроса.

Использование индекса продемонстрировано через `EXPLAIN QUERY PLAN` с указанием `INDEXED BY`.

**№10. Unit-тесты базы данных**

Разработаны 13 автоматических тестов с использованием pytest.

Проверяются:
- Создание таблиц.
- Вставка данных.
- Отсутствие дубликатов.
- Параметризованные запросы.
- Поиск несуществующего сотрудника.
- Защита от SQL-инъекций.
- Фильтрация по зарплате.
- Объединение таблиц через JOIN.
- Создание индекса.
- Поиск с индексом.
- План выполнения индексированного запроса.
- Ограничение внешнего ключа.
- Запрет отрицательной зарплаты.

Тесты используют отдельную базу SQLite в оперативной памяти.

## Структура проекта

- `database.py` — подключение к SQLite и создание таблиц.
- `insert_data.py` — вставка демонстрационных данных.
- `parameterized_queries.py` — параметризованные запросы.
- `join_queries.py` — объединение таблиц через JOIN.
- `indexing_search.py` — индексация и поиск.
- `tests/test_database.py` — автоматические тесты.
- `requirements.txt` — зависимости проекта.
- `.gitignore` — исключения Git.

## Установка зависимостей

Требуется Python 3.9 или новее.

Модуль `sqlite3` входит в стандартную библиотеку Python.

```bash
py -m pip install -r requirements.txt
```

## Создание базы данных

```bash
py database.py
```

Будет создан файл `company.db` с таблицами `departments` и `employees`.

## Вставка данных

```bash
py insert_data.py
```

Программа добавляет демонстрационные записи сотрудников и отделов.

## Параметризованные запросы

```bash
py parameterized_queries.py
```

Программа предлагает ввести имя сотрудника и минимальную зарплату.

## Выполнение JOIN

```bash
py join_queries.py
```

Программа выводит сотрудников с названиями отделов.

## Индексация и поиск

```bash
py indexing_search.py
```

Программа выполняет поиск по имени и выводит план выполнения запроса.

## Запуск тестов

```bash
py -m pytest -v
```

Результат локальной проверки: 13 тестов успешно пройдены.

## Примечание

Файл `company.db` не загружается в репозиторий, поскольку указан в `.gitignore`.

База данных создаётся автоматически при запуске `database.py`.

Тесты работают с отдельными базами в памяти и не изменяют основную базу данных.
